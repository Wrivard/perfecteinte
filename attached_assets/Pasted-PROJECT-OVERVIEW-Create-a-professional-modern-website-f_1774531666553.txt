PROJECT OVERVIEW
Create a professional, modern website for Esthétique Auto PP, an auto detailing business in Laval, Quebec. The site should closely replicate the layout and structure of the existing Webflow site (https://esthetiqueautopp.webflow.io/) while being built in React/Next.js for future feature expansion.

DESIGN SYSTEM & BRANDING
Color Palette (Extract from logo)

Primary: Deep Blue/Navy (from logo)
Secondary: Bright Red/Crimson (from logo accent)
Neutral Dark: #1a1a1a (text)
Neutral Light: #f8f9fa (backgrounds)
White: #ffffff
Accent Gray: #6c757d

Typography

Headings (H1): 48-60px, Bold (700-800), Line height 1.1
Headings (H2): 36-42px, Bold (700), Line height 1.2
Headings (H3): 28-32px, Semi-bold (600), Line height 1.3
Taglines/Subtitles: 18-20px, Regular (400), Line height 1.5
Body Text: 16px, Regular (400), Line height 1.6
Font Family: Modern sans-serif (Inter, Poppins, or similar)

Design Principles

Border Radius: Consistent 6px for all cards, buttons, images
Container Width: 1200px max-width, centered
Spacing: Consistent padding (80px vertical sections, 24px internal padding)
NO fading/gradient backgrounds - Use solid colors only
Clean, minimal animations: Fade-in on scroll, subtle hover effects (scale 1.02-1.05)

ANIMATIONS & INTERACTIONS
Scroll Animations:

Fade-in when elements enter viewport (IntersectionObserver)
Slide-up for cards/sections (translateY 20px to 0)
Stagger effect for grid items (0.1s delay between items)
Duration: 0.6-0.8s, ease-out timing

Hover Effects:

Buttons: Background darken 10%, scale 1.02
Cards: Lift (translateY -4px), shadow increase
Images: Zoom 1.05, maintain border-radius
Links: Underline expand from center

Loading Animation:

Skeleton screens for images
Smooth page transitions
